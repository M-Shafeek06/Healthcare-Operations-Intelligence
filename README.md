# Healthcare Operations Intelligence Platform

An enterprise-style healthcare analytics platform built with Power BI to provide a unified view of hospital operations, patient activity, clinical services, and financial performance.

## Project Overview

This project analyzes healthcare operations across multiple functional areas and presents the results through an interactive Power BI solution.

The platform includes 9 analytical dashboards:

- Executive Overview
- Hospital Operations
- Patient Analytics
- Emergency Analytics
- Surgery Analytics
- Laboratory Analytics
- Physician Performance
- Pharmacy Analytics
- Financial Performance

## Key Features

- 17-table healthcare data model
- Power Query-based data cleaning and transformation
- DAX-based business KPIs and analytical measures
- Interactive slicers and cross-filtering
- Time-based and year-over-year analysis
- KPI comparisons and conditional formatting
- Power BI Service deployment
- Published Power BI App

## Technology Stack

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel
- Power BI Service

## Dashboard Modules

| Dashboard | Focus |
| --- | --- |
| Executive Overview | Overall healthcare performance |
| Hospital Operations | Hospital capacity and operational metrics |
| Patient Analytics | Patient demographics and utilization |
| Emergency Analytics | Emergency volume, severity and outcomes |
| Surgery Analytics | Surgical activity and outcomes |
| Laboratory Analytics | Laboratory testing and performance |
| Physician Performance | Physician workload and performance |
| Pharmacy Analytics | Pharmacy activity and medicine utilization |
| Financial Performance | Revenue, insurance, patient contribution and discounts |

## Data Model

The solution uses a 17-table analytical data model consisting of healthcare fact and dimension tables covering patients, hospitals, doctors, departments, diseases, treatments, admissions, appointments, emergency services, surgeries, laboratory services, pharmacy transactions, and billing.

## Power BI Service

The completed solution was published to Power BI Service and organized as a dedicated Power BI App for end-user consumption.
